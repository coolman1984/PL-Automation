# Portable Windows delivery

## Production rule

Give the user the complete `P_L_Excel_Agent` folder generated by
`BUILD_PORTABLE.bat`. The user does not install Python or packages and should
not copy the executable out of its folder.

## Build once

Use a Windows 10/11 x64 build computer with 64-bit Python 3.12, 3.13, or 3.14.
The supplied wheelhouse already contains all required packages for those three
versions:

1. Run `BUILD_PORTABLE.bat` directly; no internet is required.
2. Deliver `release\P_L_Excel_Agent_Windows_x64_Portable.zip`.

Run `PREPARE_OFFLINE_PACKAGES.bat` only when intentionally refreshing the
locked wheelhouse.

PyInstaller must build the Windows release on Windows; it is not a
cross-compiler. Keep the generated `SHA256SUMS.txt` with the release.

## User operation

1. Extract the complete ZIP to a normal writable folder.
2. Run `SELF_CHECK.bat` once.
3. Drag the authorized workbook onto `RUN_A08.bat`.
4. For NASCA-protected files, open the exact file manually in Excel first.

## Repair policy

The packaged application is the primary path. `REPAIR_OFFLINE.bat` is only a
source-mode fallback and creates `.runtime_env` beside the application. It
never installs globally, changes PATH, or requires internet. It needs a working
64-bit Python 3.12, 3.13, or 3.14 because the production executable already
carries its own runtime.
